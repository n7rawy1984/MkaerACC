# M3 — Posted project-cost ledger

Implemented: Accounting Reports now includes a date-bounded ledger of posted expense-account movements, grouped by Project or Company overhead, with transaction details and English/Arabic Excel and PDF exports. All authorized Projects remain reportable, including CLOSED Projects. No journal, source assignment, document, balance, permission or subscription is changed.

Scope/dependency: this completes the next independent reporting/reconciliation increment supporting PRJ-02/03 and FIN-01/04. Activation and unposted source assignment were already implemented. Further lifecycle transitions, posted dimension corrections, split/indirect allocation and WIP require the policies below. Reporting the existing posted facts needs none of those new policy choices. This report is not a profitability statement, WIP valuation, opening balance or complete Project-cost balance.

Accounting basis: include only existing `EXPENSE` account lines, debit less credit, by **journal posting date**. Group using each line's actual `project_id`; never infer a Project from a name or source text. Asset/WIP/cash/payable movements are excluded. Supplier/subcontract settlement does not repeat cost. Payroll cost is included only when visible under existing restrictive Payroll RLS. A reversal is counted on its own posting date and retains the original journal/source reference, even when the original lies outside the selected period. Current Expense status is not used to remove an earlier period's original posting. Every displayed movement derives from exactly one immutable journal line.

Controls: authenticated browser SELECT only; existing Company/accounting and Payroll RLS remains authoritative. The reader applies Company filters to every query, validates every returned Company and Project/Account/entry link, rejects duplicate/inexact/unbalanced/incomplete data, reads complete balancing journals before selecting cost lines and verifies known Expense/Certificate source references and Project relationships. Contract IDs are retained from Certificates. Unknown source types retain their actual journal/source references without invented classification. Keyset traversal reads until an empty page, so a server cap below the requested 500 rows cannot truncate results. A second immutable-header capture rejects postings that changed during reading; new postings after capture require refresh. This is a captured read, not a database transaction snapshot or a guarantee that no later postings exist.

UI: existing Accounting Reports entry point and shared styles; explicit period/Project selection, loading/error/empty/visible-zero states, error focus, paginated movement details, internal horizontal scrolling and RTL/LTR. Filter changes hide stale totals/exports. Actor/Company/role changes and Auth invalidation clear results; before/after session checks discard stale responses. Export uses the same captured result as the screen. Company identity, inclusive dates, exact numeric amounts, Project/account/source classification, posted/reversal status, reversal lineage, source/contract references and totals are retained. Management visibility limitations and exclusion of unposted sources/assets/WIP are explicit. PDF reuses Print / Save PDF; existing Excel numeric-precision guard remains.
