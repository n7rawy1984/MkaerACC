## Missing capabilities completed

Existing `/payroll` navigation now includes **WPS & final settlement / حماية الأجور ونهاية الخدمة**. The commercial workspace reads confidential Company state through a STABLE RPC, not privileged browser SQL.

* Accounting Admin records employer/scheme/contracted agent identifiers and employee identifiers/routing/IBAN or salary-card account. UAE IBAN structure and MOD97 are validated; duplicate scheme/person identifiers are denied. Company accounts and configuration are never invented. Configuration versions and audit evidence are immutable.
* Accountant prepares a WPS review snapshot from a live posted payroll. Earned salary, separate advance recovery, net cash entitlement, actual non-reversed payments and outstanding salary are derived from existing canonical entitlements/recovery/payment records. Missing setup is explicit. The review cannot create salary, cash movement or GL entries.
* Admin records evidenced **external** submission → agent acceptance/rejection. This is manual status tracking, not an integration. Preparation, recipient setup or financial changes invalidate a stale submission. One logical run per payroll prevents duplicate submission; an accepted run cannot be prepared again. A rejected run can be prepared again. Agent refunds/partial re-submissions are not automated.
* Authorized Excel and PDF/print outputs identify themselves as **review outputs, not bank files**. Fresh permission-checked data is read before export. Existing salary payments remain the authoritative reconciliation; acceptance by an agent never marks salary paid.
* Scoped gratuity: verified foreign full-time monthly-paid employees under the UAE private-sector traditional scheme. National pensions, alternative savings schemes, part-time, domestic workers and other jurisdictions are explicitly unsupported by this calculator. Admin/domain verification of applicability and lifetime unpaid days is required; no inference from a person's name or Company is made.
* Calculation uses last dated basic salary, verified start/end and unpaid service days; the final day must match existing employment terms. The 21/30-day bands and two-years' wage ceiling use exact numeric arithmetic and round once to fils. **Actual service days/365 is a disclosed product calculation convention**, not a claim that Article51 mandates that day-count convention. The ceiling uses the fixed wage in the dated terms (basic plus allowances); allowance recognition and category must be verified for the individual. No arbitrary entitlement override is accepted by the posting command.
* Draft → Admin approval → canonical accrual → partial/full actual Treasury payment → reconciliation. Dedicated existing expense and Party-required liability accounts are explicitly mapped by Admin with account permission; no accounts, opening balances or configuration are created automatically. A first-recognition/no-prior-provision scope is explicit. Existing employee control-account balances must be zero before recognition. A conflicting prior provision is blocked for reconciliation, never expensed again.
* Accrual debits gratuity expense and credits employee liability; payment debits that liability and credits actual Company Treasury. No extra salary expense, advance recovery, Project cost or cash is created. Before payment/correction the control GL must reconcile to this gratuity subledger. Historical service is not silently assigned to a current Project.
* Audited unposted recalculation resets approval. Posted calculations and payments remain immutable; a genuine payment correction/returned funds uses canonical reversal. Accrual reversal requires zero live paid amount. Reversed drafts can be corrected with the same document/audit history. Different request keys cannot repeat a live payment reference or an already recognized employment spell.

* [UAE Government wage-payment guidance](https://u.ae/en/information-and-services/jobs/employment-in-the-private-sector/payment-of-wages): current official indexed guidance refers to Ministerial Resolution340/2026, superseding reliance on598/2022. Direct page extraction and the current MOHRE resolution PDF were not readable through this session. No penalty, due-date exemption or compliance-threshold engine was inferred.
* [Emirates Islamic official Salary WPS file guide](https://www.emiratesislamic.ae/-/media/ei/pdfs/business-online/salary-and-utility-payments/ei_businessonline_salary_wps_file_creation_user_guide.pdf): actual bank-specific EDR/EVP/SCR specification inspected; [DIB WPS service](https://www.dib.ae/business/products-services/wages-protection) confirms contracted agent setup. These do not establish a current applicable format for an unspecified Company's agent. **No SIF/bank-file generator, submission-ready claim or direct bank/MOHRE integration is implemented.** An applicable current provider specification and validated examples remain necessary for an adapter.

Statutory scope is separate from employer policy. Scheduled-minute salary proration and explicitly approved overtime remain existing Company policies; this increment does not reinterpret them as universal statutory rates. Gratuity is one final-settlement component: unpaid salary, accrued leave cash-out, notice pay, lawful deductions, pension/alternative schemes and existing provision/IAS19 reconciliation are not automatically calculated or combined here. Keep their original requirements open.

## Security, database and recovery

New append-only `hr_commercial_events` uses RLS/payroll permission and no authenticated direct-write grant. Commands derive actor, require active Company/profile/membership, serialize on existing attendance and operational finance locks, validate master/dimension/state/version, hash canonical JSON with trimmed evidence, and record an actor-bound request receipt. Concurrent duplicates return the saved result or reject stale versions; document and journal commit together. Canonical journal, balance, fiscal/final-year and Treasury guards remain active. Private helpers are not browser-executable. Existing payroll journal privacy is extended to gratuity and its reversals while retaining the existing function OID/policy references; Management Viewer is not widened. Sensitive data remains in component memory and is cleared on scope/session changes; uncertain commands offer identical retries and block new actions until resolved. There is no new authentication system or service-role browser path.
